第 1 天 · oreo-e2e 怎么用 Genie

配置与环境

genie.properties

公共默认值

Edge 浏览器、headless、超时、trace 模式、risk engine 用 MOCK、元素文件路径

<env>.properties

各环境的地址和账号

dev、sit、qa、uat、pt；默认 qa，由 @GenieOptions 指定

# 切换环境
-Dgenie.properties=./src/test/resources/<env>.properties

地址和账号只能放在 properties 里，不能写进代码、feature，也不能提交。账号按角色通过 config/TestUser 获取。

可以打开 genie.properties 看一下有哪些配置项，但不要在屏幕上展示真实的地址和账号。
