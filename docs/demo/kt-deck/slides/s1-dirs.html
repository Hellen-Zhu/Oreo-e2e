目录地图

目录放什么
features/api、features/ui按领域分目录，一个 event 一个 feature
snippet/apiAPI 的业务动作和结果断言
snippet/ui/flows、pages、componentsUI 三层：业务流程、页面原子操作、通用组件
glue/api、glue/ui、glue/hooksJava step 定义和 hooks
data/api、ui、setup、dat，common.jsoncase 数据、前置条件数据、产品 dat、公共块
elements/pages、componentsUI 定位器
*.properties环境地址、账号和运行模式

snippet 和 glue 在 src/main；features、data、elements 和 properties 在 src/test/resources
