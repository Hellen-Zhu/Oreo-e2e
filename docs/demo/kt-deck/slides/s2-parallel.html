第 1 天 · oreo-e2e 怎么用 Genie

并行：多进程，不是多线程

master 进程

加载 feature，按 FEATURE 模式切成工作单元，排队

子 JVM 1：串行跑一个 feature

子 JVM 2：串行跑一个 feature

子 JVM 3：一个结束，马上补下一个

为什么

Cucumber-JVM 不是线程安全的

DISCRETE 目录

每个子进程有独立临时目录，读文件必须走 classpath

对 case 的要求

不依赖其他 feature 会改的数据，比如固定的 trade 或用户设置

细节见 docs/genie-parallel-execution.md 第 1 节。并发数不是越高越快：每个子进程都是完整的 JVM，UI case 还有自己的浏览器。
