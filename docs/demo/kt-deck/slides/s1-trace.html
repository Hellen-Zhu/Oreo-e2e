04

在公司机器上，用最窄的 filter

# 打印一个 case 的数据（离线）
mvn -Ptest-data process-test-classes "-Dexec.args=case TC-…"

mvn -B test -Dtest=OreoTest "-Dcucumber.options=--name ^\[TC-…\].*$"

这是第 1 天的收尾，也是最重要的部分，留足 15 分钟。挑一个简单的 trade_creation API case。追一遍，比讲十遍概念都有用。
