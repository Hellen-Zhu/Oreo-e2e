第 1 天 · oreo-e2e 怎么用 Genie

入口：OreoTest，对照 RestTest 看

注解作用要记住
@RunWith(Genie.class)由 Genie 接管 JUnit 的运行mvn test -Dtest=OreoTest 跑的就是 Genie
@CucumberOptionsfeature 在哪、glue 在哪、默认 tagglue 有两个来源：Java 包和 snippet
@GenieOptions环境配置文件、并行方式qa.properties，FEATURE 模式，3 个并发

固定 tag：not @wip 和 @ADO#trade_creation，命令行的 filter 会和它们叠加。所以 mvn test 不等于全量；跑出 0 个 case 时，先查 tag。选 case 只用 -Dcucumber.options，不用 -Dcucumber.filter.*。

打开 src/test/java/com/example/module/oreo/OreoTest.java 对照讲。SeedTest 是另一个入口，用来给 UAT 批量下 SIT seed，不是测试，mvn test 不会跑它。
